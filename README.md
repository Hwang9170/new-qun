# 펀더멘탈 랩 — 기업 펀더멘탈 분석 사이트

재무제표를 넣으면 기업의 **수익성 · 성장성 · 안정성 · 현금흐름 · 밸류에이션**을 한 화면에서 분석하는 정적 웹사이트입니다. 빌드 과정이나 서버, 외부 라이브러리가 필요 없습니다.

## 기능

| 영역 | 내용 |
|---|---|
| 개요 | 5개 영역 점수와 종합 등급(A–E), 핵심 지표 9개(양호/보통/주의 배지 포함), 자동 분석 코멘트 |
| 재무 추이 | 매출·이익, 이익률, ROE/ROA/ROIC, 현금흐름, 부채·유동비율, EPS/DPS 차트(호버 툴팁 지원) |
| 비율 분석 | 연도별 20여 개 재무비율 표 |
| 재무 건전성 | Piotroski F-Score(9개 항목 체크리스트), Altman Z-Score(구성 요소 분해 포함) |
| 가치평가 | 2단계 DCF 계산기, S-RIM, 그레이엄 넘버, 할인율 × 영구성장률 민감도 표 |
| 기업 비교 | 등록된 모든 기업의 핵심 지표 비교(행을 클릭하면 해당 기업으로 이동) |
| 데이터 입력 | 연도별 재무제표 편집, 스프레드시트 붙여넣기, JSON 내보내기·가져오기(브라우저 localStorage에 저장) |

라이트/다크 테마와 모바일 화면을 지원합니다.

## 실행

```bash
# index.html을 브라우저로 바로 열어도 됩니다
npm start        # http://localhost:3000
npm test         # 분석 엔진 단위 테스트
```

GitHub Pages, Vercel, Netlify 등 정적 호스팅에 그대로 배포할 수 있습니다.

## 데이터 입력 단위

- 금액: **억원** / 주가·EPS·DPS: **원** / 주식수: **주**
- DART 사업보고서의 연결재무제표 값을 넣으면 됩니다. 차입금은 단기·장기 차입금과 사채의 합계(이자부부채)입니다.

## 구조

```
index.html          화면 구성
css/style.css       스타일(라이트/다크 토큰)
js/data.js          가상 샘플 기업 4곳 + 입력 항목 정의
js/analysis.js      분석 엔진(순수 함수, Node에서 테스트 가능)
js/charts.js        의존성 없는 SVG 차트
js/app.js           UI 로직
tests/              node:test 단위 테스트
```

> 샘플 기업(한빛반도체, 누리식품, 대양중공업, 온새미로플랫폼)은 모두 **가상의 데이터**입니다. 분석 결과는 참고용이며 투자 권유가 아닙니다.
